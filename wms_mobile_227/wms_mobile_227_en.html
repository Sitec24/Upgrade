5.0.227 Release Notes

  • Added a function to display information about the current warehouse employee. Employee data is available in the "Operations" menu section.
  • During scanning, the mechanism that forcibly replaces a space with the "\x1d" character has been removed. For the "Keyboard Event" scanning mode, a setting "Convert space to GS character (ASCII 29)" has been added. When enabled, a space will be replaced with the value "\x1d".
  • Added integration with "Mertech" equipment.
  • Added display of the full build number in the application version shown to the user ("VersionName" field).
  • Fixed other errors.
